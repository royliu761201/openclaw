# Antigravity 横向分布记忆全解 (Multi-Node Memory Architecture)

为了让分布在不同物理节点上的 Antigravity Agents（蛋蛋）保持一致的上下文认知，避免“我说过的话它忘了”、“它昨晚干的事我不知道”等问题，我们把它的“脑组织”（Memory）切割成四个分层，并制定了**“一拖二全互联记忆网络”**。

## 🧠 记忆四分层 (The Four Lobes of Memory)

### 1. 临时海马体 (Conversation State / UUID 目录)
- **存储位置**：`~/.gemini/antigravity/brain/<UUID>/`
- **内容涵义**：存放具体每一次对话框聊天里的任务检查单 (`task.md`)、您让它写的草稿、以及它自动生成的截图和报错快照。
- **作用域**：极其细颗粒度的上下文追踪。如果 01 昨天在修某个 bug，留下了长篇的回溯日志，02 今天早晨拿到后，接着问那段 bug 就能直接接手。

### 2. 长期皮层区 (Skills & Specifications)
- **存储位置**：`~/Documents/projects/openclaw/skills/` 和 `docs/standards/`
- **内容涵义**：您订立的核心规则。包括昨天咱们合并的《大一统规范》，以及它是以什么身份（总架构师、Egg Assistant、24 监控者）存在。
- **作用域**：跨越对话周期的“本我意识”。所有的任务指令，最终都必需下沉为这里的 Markdown 规范，否则蛋蛋过几天绝对会遗忘。

### 3. 全局神经元网络 (Secrets & Env Config)
- **存储位置**：`~/.openclaw_secrets/secrets.json` 及环境变量文件。
- **内容涵义**：包含了密码、Kaggle 密钥、HF Tokens 与跳板机的网络拓扑图。
- **作用域**：使得 01 知道的服务器端口、账号，02 完全知悉，无痛登录。

### 4. 短期触发列队 (Remote Command Message Queue)
- **存储位置**：`~/.gemini/antigravity/brain/02_INBOX.md` (+ 刚装入 02 的 `inboxwatcher`)
- **内容涵义**：这是最新的机制，打破了“只能由人触发 AI”的规律。01 想到要让 02 做什么，直接将其写入 01 硬盘的 INBOX；经过同步到达 02 后，02 的 AppleScript 监听器会马上吃进它的脑子并自主执行。这是节点间的心电感应。

## 🔀 记忆同步与覆盖原则 (Sync Pipeline)

目前我们依赖 `roy-003` (100.108.106.119) 这个堡垒机充当“真理集散中心 (Source of Truth)”。

每天进行的自动同步（或者像今天这样的最初一次海量初筛）遵循以下机制：
1. **[上传态]** 01 会将以上四个脑区中被**修改/新增过**的数据强制打包发送到 03 上的中枢池内。
2. **[拉取态]** 02 也会每天准时苏醒，通过 `rsync -ua`，把 03 里面所有比自己新的脑区快照原封不动拉过来**覆盖（更新）**自己。

**为何一定要有 03 做中点？**
因为如果 01 盖着盖子休眠并且被公司网络强行掐断，02 在实验室单体运转是没有来源供血的。03 作为一个无显示器的服务器，永远在线，它不仅存有您最新的模型权重大文件（在 `openclaw_data` 里），也存着蛋蛋们关于您最近发号施令的“云端大脑记忆库”。
