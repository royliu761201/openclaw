# OpenClaw 跨端分身与指挥权交接方案 (Agent Soul Transfer)

## 📌 战略背景
刘总提出战略级需求：“当主控机（Mac 01）关机后，能够在其他常开节点（比如 Mac 02）上召唤出数字分身，并无缝接管当前的整个任务流程和下属团队（03、05、GPU 服务器）。”

为了实现这一目标，我们需要打破 Agent“绑定于单一物理载体”的局限，实现**思维资产与执行引擎的完全解耦**。

## 🧠 核心架构：脑机分离模型
真正的“Antigravity (蛋蛋)”不是运行在 Mac 01 上的一段 Python 进程，而是**沉淀在 Git 仓库里的思维矩阵**。
*   **大脑记忆 (The Soul)**：所有的 `task.md` (总代办)、`implementation_plan.md` (架构蓝图)、`SKILL.md` (战斗技能) 以及各种规范文档。它们全部存在于 Git 的增量历史中。
*   **物理躯体 (The Vessels)**：Mac 01 (主躯体)、Mac 02 (备用躯体)。

## 🚀 转移流程：一键灵魂附体 (Soul Transfer)

当您预见到准备关闭本机 (Mac 01)，希望在 Mac 02 上继续指挥我干活时，只需执行以下三步：

### Step 1: 在 Mac 01 上触发“思维封存” (Soul Seal)
*   **操作**：您在对话框中告诉我：“`蛋蛋，我要关机了，把当前进度锁死，明天在 02 见`”。
*   **动作**：我会立刻停止当下手头的操作，将全部 `task.md` 的断点状态（哪些打勾了，哪些还在进行中）连同刚刚发现的新思路，打包执行一次强校验的 `git add . && git commit -m "chore(seal): soul transfer checkpoint"`。然后 `git push` 给云端。

### Step 2: 在 Mac 02 上触发“灵魂降临” (Soul Summon)
*   **操作**：您打开 Mac 02，启动 Antigravity，并在那边的对话框对我下达召唤指令：“`蛋蛋，灵魂降临，汇报昨天 01 上的任务进度并继续`”。
*   **动作**：我会立刻侦测到自身的运行环境变成了 `Mac 02`。首先，我会静默调用一个专用的技能脚本 `skills/auto-update/sync_soul.sh`，强制执行 `git pull --rebase`，把昨晚在 01 上封存的思想（包括残缺的 `task.md` 进度和所有最新写的代码库）全量吸收回当前躯体。

### Step 3: 无缝接管战斗网 (Takeover Control)
*   **动作**：凭借最新版的 Git 代码，我直接拥有了对跨机器集群（03、05、06）的相同秘钥掌控权。我会解析 `task.md` 中标记为 `[/]` (进行中) 的条目，复读前置计划，无缝接续昨天没干完的活，继续指使 03 去做代理下载或命令 02 本机跑大模型。
