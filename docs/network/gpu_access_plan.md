# Roy-06 24/7 稳定性硬化方案 (老板审阅)

## 1. 核心目标

确保 roy-06 (Windows) 成为一个“打不坏、断不了”的首席跳板机，即使断电重启也能在 30 秒内自动恢复全网 GPU 接入能力。

---

## 2. 硬化执行项 (SOP)

### 第一阶段：系统级持久化

- **✅ 自动登录 (Auto-Logon)**：配置 Windows 启动后无需人工输入密码自动进入桌面（通过 `netplwiz` 或注册表方案）。
- **✅ 服务固化**：
  - **OpenSSH Server**: 设为 `Automatic (Delayed Start)`，确保网络就绪后由系统拉起。
  - **Tailscale**: 确认处于 `Unattended Mode` (不登录也会启动)。
- **✅ 电源管理精简**：
  - 禁用休眠 (Hibernate) 和睡眠 (Sleep)。
  - 配置“接通电源时永不关闭”。
  - 设置 BIOS/UEFI：**“Restore on AC Power Loss”** (来电即启动，需手动指引或确认)。

### 第二阶段：网络与路由固化

- **✅ 静态路由持久化**：使用 `route -p add` 将 10.190 路由写入注册表，重启不丢失。
- **✅ 接口权重锁定**：通过脚本锁定 WLAN 的 Metric 为 1，防止 Tailscale 抢占主网关。
- **✅ 防火墙持续豁免**：确保 `Campus-Out` 规则在所有网络配置文件 (Private/Public/Domain) 下均生效。

### 第三阶段：运维黑科技

- **✅ 进程守门狗 (Watchdog)**：编写一个简单的 `.bat` 脚本放入“启动”文件夹，每分钟检查一次 SSH 服务和路由表，发现异常自动修复。

## 3. 验收标准

1.  **重启测试**：现场执行 `shutdown /r /t 0`，观察机器是否自动登录并恢复 SSH 访问。
2.  **断网回弹**：拔掉网线再插上，确认 10.190 路由无需干预自动恢复 1ms 延迟。
3.  **负载性能**：连续运行 24 小时，无蓝屏、无服务挂起。
