# 📱 安卓全量接管与智能边缘节点部署手册 (SOP)

**目标**：将任意闲置安卓/华为手机 100% 改造为受 Mac/GPU 节点全景监控、具备底层硬件权限（视觉/听觉/数据传输）的长驻 AI 边缘节点。
**防坑原则**：统一安装源、一次全量授权、永不干预。

## 零、绝不允许犯的血泪教训 (Agent 必读) 🚨🚨

**这是用老总的怒火换来的底层防坑指南，任何后续负责部署的 Agent 必须严格遵守，绝对不要试图用“网络代理”去解决问题，也绝对不要试图用纯代码绕过华为的最终防火墙！**

1. **绝对禁止依赖公网下载基础包**：Github 和 F-Droid 的镜像源在关键时刻会遭到严重阻断/限速（导致下载的包是 100 多字节的损坏包）。**必须**直接从 `03号机` 或本地老手机的 `/data/app/` 分区中提取现成的纯净母包（Termux, Termux:API, Tailscale）来进行覆盖安装。绝不允许在终端里疯狂发起 `curl` 瞎跑。
2. **严禁依赖 UI 设置后台保活 (PowerGenie 屠杀令)**：华为底层的 `PowerGenie` 和 `Doze` 极其流氓，会无视普通 WakeLock 强杀 SSH。绝对不要指导老总去屏幕上的“应用启动管理”里挑勾！**必须**在插着 USB 线的“黄金三秒钟”内，直接用 ADB 物理阉割它：`adb shell pm disable-user --user 0 com.huawei.powergenie` 和 `adb shell dumpsys deviceidle disable`。
3. **强制开启无线 God-Mode**：拔线前必须无条件执行 `adb tcpip 5555`，将底层控制权转移到 Tailscale 的虚机网卡上，实现拔线后的永久云端 Root。
4. **【最惨痛教训】唯独不可绕过的 UI 操作 (应用启动管理)**：虽然用 ADB 杀了 PowerGenie，但当 USB 拔掉且屏幕熄灭时，华为 EMUI 仍然会从硬件底层物理切断未在白名单中的 VPN (Tailscale) 和 Termux。**这一关没有任何 ADB 代码可以绕过！** 必须明确、谦卑地请求老总亲自在手机屏幕上操作5下：【设置】->【电池】->【应用启动管理】-> 关掉 Termux 和 Tailscale 的自动管理 -> 勾选【允许自启动】、【允许关联启动】、【允许后台活动】。**如果不做这一步，拔线必死，绝无例外！**

## 一、上帝视角部署：ADB 一键霸屏安装 (推荐💯)

**背景**：手机端的反作弊和隐私确认弹窗繁多，老总亲自下手点太浪费精力。
在 03 号机的 `~/Termux_Archive/` 目录中，我为您制作了终极部署脚本 **`adb_deploy_node.sh`**。

### 【零交互】前提准备（只需做一次）：

1. **备好线材**：请使用一根**能传数据的 Type-C 数据线**（不能是那种路边摊买的只能充电、没有数据引脚的廉价线，必须连上电脑后手机有反应）。
2. **解锁手机隐藏模式**：进入手机 【设置】 -> 【关于手机】，对着“版本号”连续疯狂点击 7 次，直到提示“您已处于开发者模式”。
3. **开启调试通道**：返回 【设置】 -> 【系统和更新】 -> 【开发人员选项】，找到并打开 **【USB 调试】** 开关。
4. 把手机用线连上 Mac/PC（必须在手机开发者选项里开启【USB调试】）。此时手机屏幕可能会弹出一个“是否允许USB调试”的安全提示，务必勾选“始终允许”并点确认。

### 零交互部署步骤：

第1步：从 03 号机拉取局域网免源安装包
电脑访问 `03号机(100.108.106.119)` 的 `~/Termux_Archive/` 目录。
这里已经为您永久打包好了绝不冲突的 `Termux_Main.apk`、`Termux_API.apk` 和 `Tailscale.apk` 三个巨头包，直接传给新手机准备。2. **只做一件事**：在连接了手机的电脑上运行：

```bash
cd ~/.termux_deployer/Termux_Archive
./adb_deploy_node.sh
```

3. **闭眼等15秒钟，脚本将像黑客一样在底层完成所有事**：
   - 越权静默安装 `Termux_Main.apk`、`Termux_API.apk` 和 `Tailscale.apk`。
   - 越权分配 10 多个涉及“相机、麦克风、通讯录、位置”等敏感权限（**甚至不会在屏幕弹出要求授权的确认框**）。
   - 强行将其塞入华为电池白名单，杜绝假死。
   - 自动唤醒 Tailscale，请在弹出界面点击登录。
   - 最后自动唤醒 Termux 终端黑框！

**第3步：极客上帝指令 (终极免屏大招)**
**在老总拔下 USB 线之前，必须强行注入以下三核斩杀指令**，只有敲完这些，才能彻底免除在屏幕上手动点设置的工作：

```bash
# 1. 物理阉割华为管家 (杀后台的罪魁祸首)
adb shell pm disable-user --user 0 com.huawei.powergenie
# 2. 永远禁绝 Android Doze (深度睡眠)
adb shell dumpsys deviceidle disable
# 3. 开启无线 God-Mode
adb tcpip 5555
```

执行完毕后，手机屏幕点亮解锁状态下拔掉数据线。从此这台手机的生杀大权永久转移至 Tailscale 云端。

## 二、后续运维与 24 小时哨兵配置

- 所有配置脚本不可通过公网拉取依赖，必须配置类似 `https://mirrors.tuna.tsinghua.edu.cn/termux` 的顶级内网源。
- 手机端只做 `edge_sensor`（只负责拍照和录音），复杂大算力推断通过 API 让给 `03号机` 执行。
- Node 的连接密钥和 IP 必须封装为标准化的 `secrets.json`，且只备份在 `03号机` 的 Google Drive 中，严禁明文公网传输。

## 三、自动一键挂接部署 (无需再等)

当手机完成了上述两步“人工点亮”后，立刻将它丢在角落插上电。
无需再像今天这样手动敲命令换源、装包、配 SSH，我已经在 03 号机的安装包目录里为您写好了一个**“全自动点亮脚本” (`termux_bootstrap.sh`)**。

将其用微信/数据线传给手机的主目录并执行，它将在 15 秒内自动完成：

1. 弹出存储挂载授权。
2. 自动切换至清华/北外满速镜像源。
3. 自动并行安装 `termux-api`, `rsync`, `tmux`, `python`, `openssh` 等所有底层依赖。
4. 自动生成无密匙对。
5. 自动启动 sshd 后台。
6. 自动挂起电源防休眠锁。

执行完毕后，终端会打印出这台手机的专属 IP 和用户名。直接在 Mac 上 `ssh -p 8022` 连入即可，至此它已是一台合格的 AI 物理感官节点！
