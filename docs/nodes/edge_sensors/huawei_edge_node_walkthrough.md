# 🚀 盲侠计划：闲置手机化身 OpenClaw 边缘感官节点（终极复盘）

**项目代号**：Blind Swordsman (盲侠)
**项目目标**：将完全闲置的安卓（华为）旧手机，经过深度物理与系统改造，纳编为供 GPU 算力主节点调遣的 24/7 纯后台感官外设（眼睛、耳朵、嘴巴）。

---

## 🏗️ 最终建成架构概览

目前，共有两台“盲侠”战列舰已正式潜入专属的加密虚拟骨干网中待命：

- **盲侠 01 号节点**：`100.78.52.96` (早期老旧华为手机，纯净入列)
- **盲侠 02 号节点**：`100.88.176.68` (新加入华为手机，极致瘦身)

它们目前的共同生理特征是：

1. **彻底戒断公网依赖**：所有的运行环境、依赖源均使用了局域网直接空投或满速内网源替换，无惧任何 GitHub 或官方库网络熔断。
2. **纯净黑屏生存**：没有锁屏、没有密码、系统锁屏与息屏常亮被底核重构。
3. **免密级 SSH 穿透**：通过安全的 ED25519 秘钥和 Tailscale 内网，实现了毫秒级、免认证的绝对控制权移交。
4. **超全权限放行**：借用一次性的 ADB 上帝之手，将所有通常需要老总点屏幕授权的“硬件特权（相机、麦克风等）”永久固定并移交给了底层的黑框。

## ⛓️ 血泪跨越与防御战纪 (踩过的坑)

该项计划最艰难的战役，在于**“击败厂商定制系统的底层幽灵防御”**。
为了让 `sshd` 通信隧道在手机黑屏且拔掉线材后依然活蹦乱跳，我们经历了一场艰苦的权限争夺战：

1. **废黜 PowerGenie（杀手头子）**：曾试图用 `adb shell pm disable-user` 物理阉割了华为系统的省电精灵（PowerGenie），让它失去杀除后台的兵权。
2. **砸穿 Android Doze 与 AppOps**：曾连续打入几十行底层代码，在 Linux 内核上强行给 Termux 和 Tailscale 申请最高级别的 `WAKE_LOCK` 防休眠金牌。
3. **【最终的物理隔离锁：应用启动管理】**：我们最终发现：**华为 EMUI 开发了一套游离于安卓原生标准之外、根本不给 ADB 开后门的硬逻辑防火墙（应用启动管理）**。一拔数据线，这道防火墙立刻苏醒接管一切！
   - **破局方法**：唯独这一关不能靠代码偷懒。**唯一解法就是由人类（老总）通过肉眼与手指的 5 次点击**（在屏幕设置的电池管理中，把那两个 App 勾选“不允许自动管理 -> 允许自启动/后台活动”）。
   - 这最终且痛彻心扉的领悟，已经被作为最核心的【血泪教训】写进了 SOP 第一行（见 `huawei_termux_sop.md`。
