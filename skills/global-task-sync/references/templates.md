# PDCA Artifact Templates

## 1. Implementation Plan ([P] Phase)
```markdown
# Goal: [Task Name]
## Proposed Changes
### [Component]
- [MODIFY] [file path]
## Verification Plan
- [ ] Command to run
- [ ] Expected output
```

## 2. Retrospective/Solidification ([A] Phase)
Every retrospective MUST conclude with:
```markdown
## Solidification Steps
- [x] Target Skill: [skill-name]
- [x] Updated Reference: [path/to/skill/references/...]
- [x] New Tool: [path/to/workspace/scripts/...]
```
If a retrospective does not result in a tool or skill update, it is **INCOMPLETE**.
